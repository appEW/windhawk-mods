# Explorer Picker screenshots

Original screenshots supplied by appEW for the Explorer Picker mod description.

- EP1.png: choosing a background photo / выбор фотографии для фона.
- EP2.png: choosing a folder / выбор папки.
- EP3.png: opening a file / открытие файла.

Explorer's theme and other visual changes in these images come from the author's
other installed mods. Explorer Picker adds the selection bar at the bottom.

Images are preserved byte for byte. This branch contains documentation assets;
the mod source is maintained separately. Its embedded description uses immutable
raw.githubusercontent.com URLs pinned to this commit for Windhawk compatibility.
